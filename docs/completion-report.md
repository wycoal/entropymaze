## 物理模型

### 核心公式

1. **熵计算**
   ```
   S = Q / T
   Q = m × T (简化模型)
   ```

2. **可用能计算**
   ```
   E = Q × (1 - T₀/T)
   ```

3. **摩擦熵增**
   ```
   F_f = μ × m × g
   W = F_f × d
   ΔS = W / T
   ```

4. **传热熵增**
   ```
   T_final = (m₁T₁ + m₂T₂) / (m₁ + m₂)
   ΔS = m₁c ln(T_f/T₁) + m₂c ln(T_f/T₂)
   ```

### 参数配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 图块数量 | 15 | 固定值 |
| 总能量 | 10000 J | 固定值 |
| 背景温度 | 20°C | 可调节 |
| 摩擦系数 | 0.15 | 可调节 |
| 温度范围 | 0-300°C | 映射到灰度 |

## 使用指南

### 快速开始

```bash
# 1. 进入项目目录
cd entropy-maze-game

# 2. 启动本地服务器（任选一种）
python -m http.server 8000
# 或
npx http-server -p 8000

# 3. 打开浏览器访问
http://localhost:8000
```

### 基本操作

1. **拖拽图块**
   - 鼠标点击图块
   - 拖动到新位置
   - 释放鼠标

2. **合并图块**
   - 将图块拖到相邻位置
   - 系统自动检测并合并

3. **查看统计**
   - 实时查看可用能、熵值等数据
   - 追踪可用能峰值

### 键盘快捷键

- **N** - 新游戏
- **R** - 重置
- **P/空格** - 暂停/继续
- **G** - 切换网格显示
- **T** - 切换温度显示
- **E** - 切换可用能显示
