# Entropy Maze - 物理模型说明（v2）

> 本文档描述重构后的热力学模型。v1 使用的 `E = Q(1 - T₀/T)`、`Q = m·T` 是**热源近似**，
> 套用到有限物体上会自相矛盾（详见 §7 旧模型缺陷），v2 已全部废弃。

---

## 1. 系统定义与基准

| 项目 | 取值 | 说明 |
|---|---|---|
| 系统 | 全部能量球 | 闭口系统，以环境为基准 |
| 环境 | 温度 T₀ 的大热源 | 默认 20 °C，滑块可调 0~50 °C |
| 比热容 c | 1.0 J/(kg·K) | 常数 |
| 总内能 U_total | 10000 J | 配置值，**全程严格守恒** |
| 温度区间 | [T₀, 300] °C | 下限与环境对齐，避免"冷㶲"干扰单调性 |

**所有公式内部一律使用开尔文**，仅在展示时转换为摄氏度。

---

## 2. 状态函数

设质量 m、温度 T（K）、环境温度 T₀（K）、比热容 c。

### 2.1 内能（相对环境）

\[
U = m\,c\,(T - T_0)
\]

以环境为基准，因此"总内能"等于系统相对环境所蕴含的热量。游戏中该值恒为 10000 J。

### 2.2 熵（相对环境）

\[
S = m\,c\,\ln\frac{T}{T_0}
\]

### 2.3 㶲（可用能）

\[
E = m\,c\left[(T - T_0) - T_0\ln\frac{T}{T_0}\right]
\]

这是有限物体（闭口系统）物理㶲的标准表达式，由"可逆冷却到 T₀ 所能做出的最大功"积分得到：

\[
E=\int_{T_0}^{T} m c\left(1-\frac{T_0}{T'}\right)\,\mathrm{d}T'
\]

---

## 3. 为什么合并一定使㶲下降

令

\[
\varphi(T) = (T-T_0) - T_0\ln\frac{T}{T_0},\qquad
\varphi''(T) = \frac{T_0}{T^{2}} > 0
\]

φ 是**严格凸函数**，且 φ(T₀) = 0、φ(T₀) 处取最小值 0。

两球合并时质量与内能守恒：

\[
T_f = \frac{m_1T_1 + m_2T_2}{m_1+m_2}
\]

由 Jensen 不等式（凸函数的加权平均不小于平均点的函数值）：

\[
\frac{m_1\varphi(T_1)+m_2\varphi(T_2)}{m_1+m_2} \;\ge\; \varphi\!\left(\frac{m_1T_1+m_2T_2}{m_1+m_2}\right)=\varphi(T_f)
\]

两边乘以 c(m₁+m₂) 即得

\[
E_{\text{前}} \;\ge\; E_{\text{后}}
\]

**等号仅在两球等温时成立**。因此只要存在温差，合并就必然使可用能严格下降 —— 这正是热力学第二定律在游戏中的体现。

---

## 4. 熵产与㶲损（Gouy-Stodola）

### 4.1 合并（温差传热）

\[
\Delta S_{\text{产}} = m_1c\ln\frac{T_f}{T_1} + m_2c\ln\frac{T_f}{T_2} \;\ge\; 0
\]

（由 ln 的凹性与 T_f 的定义保证非负。）

㶲损：

\[
X_{\text{损}} = T_0\,\Delta S_{\text{产}}
\]

并且可以解析地验证

\[
E_{\text{前}} - E_{\text{后}} = T_0\,\Delta S_{\text{产}}
\]

即 **Gouy-Stodola 定理在本模型中精确成立**，两者数值恒等。代码里可用 `window.debug.verify()` 做自检。

### 4.2 摩擦（移动耗散）

玩家移动能量球做功（确认落点后沿通道真实推进的那一段距离）

\[
W = \mu\,m\,g\,d
\]

其中 d 是圆心沿通道**实际行进的路径长度**（米），绕路越远 W 越大。

物理处理：这份功全部耗散为热，并**排给温度为 T₀ 的环境**。由于"功输入 W"与"热量排出 W"相抵，能量球自身的内能与温度不变。

从物理上说这份耗散当然伴随熵产 \(W/T_0\)、㶲损 \(W\)。但它的输入机械功**来自系统之外**（玩家的拖动），
按本作现行记账口径，**不计入**左侧的「累计熵产 / 累计㶲损」——那两项只统计合并传热；
摩擦代价统一改由**净做功**承担：

\[
W_{净} = \sum W_{做功} - \sum W_{摩擦}
\]

这样两块看板各司其职：**「累计熵产 / 累计㶲损」= 系统内部不可逆性**，
**「累计做功（净）」= 实际到手的功**，绕路越多被扣得越多。

> 为什么不让摩擦给球升温？
> 若摩擦热留在球内，则 T 升高 → U 升高 → E 升高，屏幕上会出现"越移动可用能越高"的荒谬结果。
> 把耗散热排给环境，则：总内能守恒（恒为 10000 J，可作守恒校验展示）、
> 可用能只因合并而下降（全程单调）、摩擦代价计入净做功。三者自洽。

## 5. 温度分配算法

给定质量数组 mᵢ 与总内能 U_total，求各球温度使 Σ mᵢc(Tᵢ−T₀) = U_total：

1. 为每个球取随机权重 wᵢ ∈ [0.35, 1.25]，按权重分配内能份额；
2. 由 Tᵢ = T₀ + Uᵢ/(mᵢc) 得到初值；
3. 若整体超出容量 Σmᵢc(T_max−T₀)，先整体线性收缩（保证迭代收敛）；
4. 迭代 ≤12 次：把越界（高于 T_max 或低于 T₀）的球钳制到边界，
   将多出/缺少的内能按质量比例在未饱和的球之间再分配（所有未饱和球获得相同的 ΔT）。

**实测结果**（15 球，质量 4~9，U_total = 10000 J）：

- 温度分布：61.2 ~ 221.7 °C（v1 是全部被钳到 300 °C）
- 总内能：10000.0000 J（误差 < 1e-6）
- 初始㶲：约 1550 J

## 6. 单位换算

| 量 | 换算 |
|---|---|
| 长度 | `pitch = 40 px = 1 m`（配置项 `pixelsPerMeter`） |
| 质量 | 圆面积 → m，半径 `r = radiusUnit·√m`，`radiusUnit = 5.5` |
| 通道净宽 | `pitch − wallThickness = 32 px`，半宽 16 px |

因此初始球半径 11.0 ~ 16.5 px，合并后不断膨胀（终态约 55 px），
**会超出通道半宽、压在薄墙上** —— 这是刻意保留的效果：圆形体积不受墙限制，但圆心必须留在通道中心线上。

## 7. 旧模型（v1）的缺陷对照

| # | v1 行为 | 根因 | v2 修正 |
|---|---|---|---|
| 1 | 温度全部被钳到 300 °C，全场纯白 | `(E/m)·300` 量级失控 | 改为按内能份额分配 + 钳制再分配 |
| 2 | 合并熵增恒为 0 | 全场同温 | 温度真实分布，ΔS ≥ 0 |
| 3 | 摩擦使可用能上升 | `E = Q(1−T₀/T)` 且 Q 随 T 增大 | 摩擦热排给环境，图块状态不变 |
| 4 | 累计熵被瞬时值覆盖 | `totalEntropy = ...` 是赋值 | 拆分为累计量 / 瞬时量两组字段 |
| 5 | "显示可用能"恒为 0 J | `block.exergy` 从未写回 | `summarize()` 每帧写回 |
| 6 | 合并动画看不到 | 无主循环，动画不重绘 | 引入 rAF 主循环统一驱动 |
| 7 | 结算浮层重复叠加 | `checkGameOver` 缺少守卫 | 首行 `if (this.isGameOver) return` |
