# Entropy Maze - 热力学熵过程模拟游戏

## 项目简介

Entropy Maze 是一款基于 Web 的热力学熵过程模拟游戏，通过可视化的迷宫和可交互的能量图块，模拟热力学第二定律中的熵增过程。

## 核心特性

- 🌀 **无闭环迷宫**：随机生成完美迷宫（生成树），全连通且零闭合环路，每局重新生成
- 🧱 **薄墙通道**：墙只保留 8px 可见厚度，通道宽敞；墙画在网格线上，拐角自然封口
- ⚪ **圆形能量球**：本体是质点（圆心），体积用圆形表达，半径随合并不断膨胀
- 🎯 **圆心受约束**：拾取时球可自由跟随指针；确认后圆心只落在通道中心线上（沿树的唯一通路推进，绝不穿墙瞬移），但圆形可溢出通道、压在墙上
- 🖱️ **两步式操作**：点击拾取 → 移动预览（不产生物理过程）→ 再次点击确认执行
- 🔬 **严格物理模型**：有限体㶲 `E = mc[(T−T₀) − T₀·ln(T/T₀)]`，㶲损 = T₀ × 熵产（Gouy-Stodola 精确成立）
- 📊 **实时统计**：总内能守恒校验、可用能衰减、累计㶲损与累计熵产
- 🎨 **视觉反馈**：温度-灰度映射 + 温度光晕，暗色科技风

## 游戏规则

1. **初始状态**：完美迷宫的通道中随机散布 15 个能量球，总内能恒为 10000 J
2. **操作方式**（点击拾取 → 移动预览 → 点击确认）：
   - **点击**一颗能量球即拾取它，此后它附着在指针上自由移动
   - 移动期间**不发生任何物理过程**，只实时显示"确认后的变化"预览
     （移动距离、摩擦耗散、累计熵产、累计㶲损、可用能变化、是否将合并）
   - **再次点击**才确认执行：圆心沿通道中心线落到投影点，累计真实摩擦耗散
   - 落点处两球相触即自动合并（半径随质量膨胀，允许隔着薄墙相触）
   - 按 `Esc` 可放弃本次拾取
   - **双击某颗球**：直接让**这颗**球做功（不必是可用能最大的那颗）；
     判定为 ≤350 ms 内、落点移动 ≤24 px 的连续两次点击同一颗球
3. **物理过程**：
   - **摩擦**：做功 `W = μ·m·g·d`，全部耗散并以环境温度 T₀ 排给环境
     → 图块状态不变；摩擦的机械能来自系统之外，**不计入**累计熵产 / 累计㶲损，
     也不冲减累计做功，而是从**蓄能器**中支出
     → **余额不足以支付本次移动的摩擦时无法移动**，须先「做功」补充
   - **合并**：`T_f = ΣmᵢTᵢ / Σmᵢ`（内能守恒），
     熵产 `ΔS = Σ mᵢc·ln(T_f/Tᵢ) ≥ 0`，㶲损 `= T₀·ΔS`
4. **做功**（点击「做功」按钮 / 按 `W`）：
   - 只作用于**当前可用能最大的那一颗球**，把它可逆地放到环境基准态（T = T₀）
   - 该球原有的全部可用能 E 变成对外输出的功；它的内能减少 U，
     其中 E 是功、余下 `U − E = T₀·S` 作为热排给环境
   - 释放规模决定爆炸特效的大小；左下统计栏显示累计做功、做功峰值与两者的比值
   - 可逆释放，**不产生熵**；因此做功后总内能会下降（那部分能量被取出为功 + 排热）
5. **胜利条件**（页面标题下方也有说明）：让**单个能量单元的可用能**尽量大 —— 该值即本局**成绩**
   —— 把它堆成质量大、温差高的一颗；**超过 300 J** 视为达标，「单元可用能」读数转为胜利色（绿）。
   一次「做功」默认只释放可用能最大的那颗球，**双击某颗球可点名让它做功**；
   **单次释放超过 300 J 时会放一波烟花**庆祝
6. **各项读数的新口径**：
   - **做功峰值**：胜负唯一指标；`峰值/累计做功` 只是参考比值，不作判据
   - **累计做功**：**只累计能量单元释放的功**，摩擦不参与
   - **蓄能器**：`初始储能 + 累计做功 − 累计摩擦功`，初值可在控制面板滑到 **0–1000 J**；
     移动前会用它结账，不足则本次移动被拒绝
   - **累计熵产 / 累计㶲损**：**只统计合并传热**，摩擦不再计入
   - 把球全部合并为一只是收尾方式；能量预算仍为 `剩余内能 + 累计做功 + 排给环境 = 10000 J`

## 快捷键

`N` 新游戏 · `R` 重置 · `W` 做功 · `P`/空格 暂停

